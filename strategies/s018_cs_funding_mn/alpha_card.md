## 1. 基础
- **ID**: s018
- **名称**: 永续截面市场中性 funding carry（空高费率 / 多低或负费率）
- **edge 类别**: E-A 机制/结构摩擦（Funding Constraints — 杠杆拥挤付费的横截面差异）
- **寿命论证**: 资金费率机制永续；不同山寨拥挤度不一致产生可收割价差。大资金受冲击/借币/额度限制；小名义可更勤调仓。机制变弱条件：全市场费率压缩、或中性组合换手成本吃掉价差。
- **报酬来源四问**:
  1. **谁付钱**: 各币拥挤一侧的杠杆交易者（付 funding）
  2. **为何不消失**: 散户/叙事资金持续造成横截面不平衡；完全抹平需要持续库存
  3. **容量**: 中低；受最薄腿 ADV 约束
  4. **成本后**: 必须拆分 **funding PnL vs 价格 PnL**；价格腿期望不要求为 alpha，但不得系统性吃掉 funding

## 2. 定义（测试前锁定）
- **universe**: 币安 USDT-M 山寨永续（排除 BTC/ETH；排除稳定币与明显股票代币可选敏感性）。流动性: 近 7d 报价成交额中位数 ≥ $5M。
- **数据**: `binance_free_db` / history funding + 1h klines；必须经 `funding_semantics`：**`is_capped=True` 样本不得进入信号**（删失不当真压力）。
- **信号（主规格）**:
  - 在每个 funding 结算时点 t（或每日 00:00 UTC 缓冲调仓，主规格先锁 **每 8h 结算后下一根 1h open**）:
    1. 取各币「上一完整结算周期 funding」（已实现，无前视）
    2. 横截面排名；**空头腿 = funding 最高 quintile**，**多头腿 = funding 最低 quintile**
    3. 两腿等权；**Σ notional_long + Σ notional_short = 0**（美元中性）
    4. 单币权重 |w| ≤ 1/n_leg；n_leg 目标 5（不足则跳过该期）
  - **禁止**: 单币 funding 极值单独开方向仓；禁止「拥挤空头 → 做多价格」类 s005 规则
- **horizon**: 持有至下一调仓点（~8h）；主报告聚合为日/周 funding 收入与净 PnL
- **基线**:
  1. 随机中性组合（同换手约束）
  2. 仅持有多头腿 / 仅空头腿（暴露方向时必须差于中性 → 用于抓作弊）
- **成本**: 调仓腿按 **16.2bps 真实成本锚** 与 **27bps 悲观** 双列；funding 按交易所符号计入
- **判定**:
  - 主: **成本后 funding PnL > 0** 且总净 PnL > 0（样本期）
  - 价格 PnL 不要求显著为正，但若价格 PnL 显著为负且幅度 > funding，则 **NO_GO**
  - 与 wash_cvd 日收益 |ρ| < 0.3（否则标「不独立」）
  - 独立时间两段同向（以 2025-01 切）
  - n: 至少 180 个调仓期

## 4. failure（什么算证伪）

- 收益依赖单月或 <5 个币
- 去掉 funding 收入后「价格腿」本身像动量/反转在驱动且不稳定
- 防火墙被破坏仍被当成通过
- 与 s014 结果混报（对冲收租 ≠ 截面中性）
