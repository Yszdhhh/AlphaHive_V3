## 方向 A — 仓位分歧层：大户 vs 全网账户多空分歧 + net_position 拐头，作 wash_cvd 确认层

1. **假设**：washout 事件中若大户（top trader 持仓比）逆势增持/空头回补、而散户（全网账户比）仍看空，聪明钱领先散户 → 卖压枯竭后反弹更强（**edge 类别：E-C 信息/价格发现延迟**——个人 vs 机构信息处理速度差是个人优势区）。
2. **数据**：
   - 现有（实测覆盖 2024-06-05→2026-05-27，~2 年窗）：coinglass `ls_top_trader`（top_position_long_short_ratio）、`ls_global`（global_account_long_short_ratio）、`net_position`（net_long_change_cum / net_short_change_cum）——全部本地 parquet，零拉取成本。
   - 前向新免费源（实测可达）：Binance futures/data 免费 API `topLongShortPositionRatio` / `globalLongShortAccountRatio` / `topLongShortAccountRatio`（fapi.binance.com 本机直连 OK）。**注意：该端点仅返回滚动 30 天**（startTime 早于 30 天即 `-1130 invalid`，实测）→ 无法回填，只能从今日起每日增量拉取积累（幂等任务并入 143 计划任务）。
   - 字段口径：coinglass 大户持仓比 ≈ Binance topLongShortPositionRatio（持仓量口径）、全网账户比 ≈ globalLongShortAccountRatio（账户数口径）；需做 symbol/时区对齐校验（100 风格）。
3. **检验设计**：
   - 事件定义：scan_rules v3 口径 wash_cvd 事件 ∩ 2024-06+ 覆盖窗（预计 ~600 事件，原始 n=1348 的 45%）；分歧 = top_position_lsr − global_account_lsr（事件触发前 24h 均值）。
   - 分层：T1 分歧>0（大户更偏多）/ T2 分歧<0；次检验：net_position_change_cum 事件前 24h 拐头向上 vs 向下。**只预注册 2 个分层，不扫网格**。
   - 基线：同窗 wash_cvd 默认档（同期可比，禁止全样本混合）。
   - 判定门槛：confirm−reject 168h 超额增量 ≥ +1.0pp 且 bootstrap CI 下界>0（seed=2026）、t≥3.0、独立窗口 W1/W2 同向、尾部切除后均值不转负、成本后净期望 >1.5×27bps、每档 n≥30。
4. **预期产出与证伪**：通过 → 新信息层 edge（s001 v4 增强或独立 E 系条目，需重叠率报告同 157 口径）；若增量点估计 <+0.5pp 或 CI 跨零 → 证伪"聪明钱领先"机制，认知入库（wash_cvd 已是自足信号，无需仓位确认层），不升级。
5. **风险**：
   - 数据可得性：ls 维度仅 2 年窗 → 样本约减半、分层后功效受限 → 检验前先做 MDE 声明（允许 1pp 增量被排除才可判"证伪"，否则标 exploratory）。
   - 执行可行性：Binance 免费端 30 天滚动 → 采集任务中断 >30 天即丢前向窗口（需每日计划任务 + 健康检查告警）；coinglass 已停更 2026-06-23（E21 同因），历史窗无法再扩。
   - 多重检验：严格限定 2 个预注册分层；分歧窗长/阈值自由度锁定主定义 + ±20% 敏感性。

## 方向 B — 拥挤清除强度层：wash_cvd 前置 funding×OI 联合拥挤度分层

1. **假设**：washout 事件前 24-72h 杠杆拥挤度越高（funding z 与 OI z 联合高分位）→ 清杠杆越彻底 → 卖压枯竭后反弹越强（**edge 类别：E-A 机制/结构摩擦**）。**与 146/147（已证伪 funding 极值反转）的本质区别：不做"拥挤→反转"裸信号，只做 wash_cvd 事件内的条件分层**。
2. **数据**：全现有零新源——coinglass `funding_ohlc` / `oi_ohlc`（2024-06→2026-06，实测）、前向 binance_free_db `funding_aligned` / `oi`（2026-07-12 起，实测 59 symbols）。拥挤度 = 事件前 24h funding z(30d) 与 OI z(30d) 的均值（联合分位）。
3. **检验设计**：
   - 事件定义：wash_cvd ∩ 2024-06+ 窗；按前置拥挤度 z 三分层（低/中/高）。
   - 主检验：分层 168h 超额的单调性（秩相关/Jonckheere）+ 高拥挤层 vs 默认档增量；对照同窗 wash_cvd 默认档。
   - 判定门槛：同方向 A（增量 ≥+1.0pp、CI、W1/W2、尾切、成本、n≥30/层）。
   - 预注册必写：① 与 146/147 的区别声明（条件层 vs 裸信号）；② 与 E02（liq_z>1，131/134）事件池重叠率报告；③ 拥挤定义锁定 1 组主参数 + ±20% 敏感性（窗长 24/72h、z 窗 30d），不扫网格。
4. **预期产出与证伪**：通过 → 拥挤清除条件层（若高拥挤层事件池 = E02 子集 → 合并管理不单独开，按相关性闸 >0.7 处理）；证伪条件：无单调性 或 高拥挤层增量 CI 跨零 → 认知：清杠杆深度不由前置拥挤度定价，wash_cvd 内部已充分反映。
5. **风险**：
   - 多重检验：funding 维度两度证伪（146/147），本方向最易被审为"换皮重测"——预注册里写清判定差异；高拥挤层与 E02 重叠可能使增量不独立（需重叠率先行侦察，1 个小脚本即可）。
   - 执行可行性：低（全本地数据，直接复用 155/157 基建）。
   - 数据可得性：funding_ohlc 覆盖到 2026-06-23 且前向有 funding_aligned → 无阻塞。

## 方向 C — s009×s010 叠加检验：新币期 × 低流动性 × 4h 确认 三层边际（s009 增强）

1. **假设**：s009（新币 <90d × 4h 确认，168h +5.82%）与 s010（低流动性 wash_cvd，+2.60%）事件池高度重叠（新币天然低流动性）→ 低流动性层在 s009 之上若有**边际**增量则分层仓位，无边际则合并管理防双计数（**edge 类别：E-A 机制**）。
2. **数据**：全现有零新源——`newlisting_raw`（币安 API 自拉缓存）+ coinglass klines/cvd/taker_buysell 2024-06+ 窗；注意新币期资产无 ls/funding 历史 → 本方向只用 klines/cvd/taker（与 157/158 同源口径，直接复用）。
3. **检验设计**：
   - 主检验（收缩 2×2，避免 12 格功效崩坏）：s009 事件 ∩ 低流动层 vs s009 ∩ 非低流动层，168h 超额差（confirm−reject 逻辑同 148）；流动性分层复用 155 定义（24h 成交额分层）。
   - 次检验：s009 × s010 事件池重叠率报告（157 已示范口径：wash_cvd 重叠 24%）。
   - 基线：s009 默认档；判定门槛：边际增量 ≥+1.0pp、CI 下界>0、独立窗口 W1/W2、尾切不转负、成本后净期望 >1.5×成本、每格 n≥30（预期 2×2 主格可行，完整 12 格标 exploratory）。
4. **预期产出与证伪**：通过 → 账户 D 接线规则升级（低流动加仓层 / 高流动降权）；证伪条件：边际 CI 跨零或方向在 W1/W2 不一致 → 结论"低流动性是新币期的共线属性而非独立条件"，s009 维持原样。**本方向直接服务已接线账户 D 的参数，优先级最高**。
5. **风险**：
   - 功效：两条件重叠大（估计 60-80%），分层后样本收缩 → 先算 MDE 再下判语；新币 90d 内流动性爬坡与时间锚共线 → 无法干净分离时如实报告共线性，不事后挑 regime。
   - 执行可行性：零（复用 155/157/158 基建，1-2 天出结果）。
   - 多重检验：这是**边际检验不是重测**（158 敏感性 9/9 已过，不再重跑网格）。

## 方向 D — 跨所价差张力（新免费源）+ s011 前向解除（工具线）

1. **假设**：同一合约 Binance 永续 vs Bybit 永续价差撕裂（z 极值）→ 套利摩擦/流动性分割事件 → 与 wash_cvd 组合后反弹更强，且可作市场级风暴（s011）的前向代理（**edge 类别：E-C 信息**）。附加工具线假设：coinglass 清算数据 2026-06-23 停更（E21 blocked），可用免费流重建前向清算维度解除阻塞。
2. **数据**（新免费源，实测可达性见附录 A）：
   - Bybit v5 kline（`api.bybit.com/v5/market/kline`，本机直连 OK，start 分页可回填至上市——实测取回 1 年前数据）；Binance fapi klines（现有基建）；**用"同合约跨所价差"而非"现货-永续基差"以规避与 funding 共线**。
   - OKX history-candles 本机直连 403（实测）→ 数据面收窄为 Binance×Bybit 双所；如需第三所走代理。
   - s011 解除路径：Binance `allForceOrders`（本机 404 HTML，疑似 geo 路由限制，需代理/网关验证）；若不可行 → Binance/OKX ws forceOrder 公开流自采（自 2026-08 起积累）+ 跨所价差撕裂作风暴代理。
3. **检验设计**：
   - 主检验：跨所价差 |z|>2 极端事件事件研究（对齐 151 口径：72h 冷却、基线随机横截面 bootstrap CI），双向检验；再测 wash_cvd ∩ 基差撕裂的增量。
   - 工具线：重建清算流后按 156 口径重算风暴事件（58 次→前向事件计数窗口 30 预警/60-100 正式），对齐 E21 decay 监测。
   - 判定门槛：同方向 A；工具线以"前向风暴事件流可用 + 与 156 事件定义一致"为通过标准（工具产出不要求 alpha）。
4. **预期产出与证伪**：① 基差张力信号通过 → 新维度 edge；不通过 → 认知入库（跨所价差对 wash_cvd 无增量信息）；② s011 前向解除（无论价差有无 alpha，清算流重建本身解 blocked，属确定性工程产出）。证伪条件：基差极端事件 168h 超额 CI 跨零 且 与 wash_cvd 交互增量 <+0.5pp。
5. **风险**：
   - 数据可得性：OKX 403（收窄双所，可接受）；allForceOrders 404 未决 → 需代理验证，失败则 ws 自采导致 s011 判决推迟 3-6 个月（前向积累期）。
   - 执行可行性：最高——新源回填（Bybit 分页 59 symbol × ~4.5y 1h ≈ 每 symbol ~200 请求，需限速）、双所时区/symbol 名映射、30 天滚动源的每日增量任务。建议**拆两期**：一期只做清算流重建（低成本高确定性，解 blocked），二期再做价差信号研究。
   - 多重检验：价差与 funding 共线风险用"同合约跨所价差"规避；预注册只测 2 个假设（极值事件研究 + wash_cvd 交互）。

## 方向 E — E08 谷歌趋势高分位独立复核 + wash_cvd 交互（情绪层补验证）

1. **假设**：谷歌趋势高分位周 → 散户关注度极端 → washout 后反弹更强（**edge 类别：E-B 情绪/行为偏差**）。E08 是唯一未复核的 exploratory 正结果（138：+2.35% CI[+1.30,+3.44] n=435）——按方法论 §3"独立样本复核是升级前提"，它现在是验证体系缺口而非 edge。
2. **数据**：管线已存在（138_free_sources.py 已证明谷歌趋势免费周粒度拉取）；复核用独立窗口（2024-06+ 子窗或 W1/W2 切分）而非原全窗；无需新数据源。
3. **检验设计**：
   - ① 复核：同定义换窗口 → t≥3.0、尾切、成本后净期望；② 交互：wash_cvd ∩ 趋势高分位 vs wash_cvd ∩ 非高分位 168h 增量检验。
   - 基线：随机横截面（138 口径）；判定门槛同方向 A。
4. **预期产出与证伪**：复核通过 → E08 升级 historical_pass 并作情绪确认层；不通过 → 关闭入 GRAVEYARD（证伪产出：情绪关注度无独立 alpha，与 E06 fng≥60"丢正期望"互为印证）。证伪条件：复核窗口不显著或交互增量 CI 跨零。
5. **风险**：
   - 数据可得性：周粒度 → 与 168h 持有窗重叠，独立样本有限（分层后 ~100 事件，功效声明）；趋势指数地域/代理已由 138 处理，沿用。
   - 执行可行性：低（脚本已有）。
   - 多重检验：E08 已消耗探索预算 → 需 Owner 拍板登记槽位（Q3 正式槽已满，按探索段纪律执行）。
