## 判定与局限

### 数据可用性（实测）

- **谷歌趋势（pytrends 4.9.2）**：可用。5 年历史 → 仅**周频**（Google 限制），262 周 2021-08 → 2026-08；日频仅近 3 月（today 3-m 稳定，8-m/6-m 实测间歇 400 限流，脚本内置 45s+ 递增间隔重试）。数值为相对指数（窗口内归一化 max=100），只能用于相对高低。
- **GDELT（timelinevolraw）**：可用。单请求即得**日频条数**（近 90-180 天，本次 180d 窗口），429 限流实测：连续多请求会触发分钟级封锁，需 25-30s+ 间隔 + 指数退避（脚本已实现，见 fetch_log）。
- **永续-现货基差**：**不可得**（无任何现货历史数据源）；funding 为代理，112/115 已测。

### 与收益的关联（判定口径：CI 下界>0 → GO_LONG / 上界<0 → GO_SHORT / 含0 → NO_GO）

- 表1 周频水平 → 下周 alt 收益: Pearson -0.001 / Spearman +0.018 → **无相关**（描述性，相关不是信号）
- 表2 wash_cvd × 趋势分位: 周分位-低 NO_GO；周分位-中 NO_GO；周分位-高 GO_LONG；周分位-全（复核115） GO_LONG；日分位-低(近3月子集) 样本不足(n=4<30)；日分位-中(近3月子集) 样本不足(n=5<30)；日分位-高(近3月子集) 样本不足(n=2<30)；日分位-全(近3月子集) 样本不足(n=11<30)
- 表3 GDELT 当日条数 vs 当日 btc 收益: Pearson +0.091（n=170，描述性）

### 局限

- 样本窗口差异：谷歌趋势 5 年（周频）vs GDELT 180 天（日频），两源仅近 3 月可同日对照。
- 谷歌趋势周频 + 归一化：跨年绝对水平不可比，只反映相对热度；'次日收益'在周频下退化为'下周收益'。
- GDELT 匹配的是全文含 'bitcoin' 的新闻，含噪音（重复转载、非市场新闻），且窗口短、n 小，仅描述性。
- wash_cvd 事件集中在 2022-2026，趋势周频为其最粗粒度；日分位子集 n 很小。
- 相关性检验为描述性，无多重检验校正；不构成交易信号，仅评估免费数据源价值。
