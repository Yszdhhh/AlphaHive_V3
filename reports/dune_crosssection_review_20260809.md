## 2. 链上清算（A）与交易所清算（131）是同一压力的两面还是独立维度？

**已实测回答（204）：是独立维度，不是同一压力两面。**

| 证据 | 值 | 含义 |
|---|---|---|
| 日清算量相关 | 0.235 | 低——两个市场几乎独立 |
| 峰值日重叠 | 15/32（链上）vs 35（交易所） | 不到一半重叠 |
| wash_cvd 事件分层 | 链上激增日增量 **-1.91%**（显著负）vs 交易所激增日 **+3.97pp**（显著正） | **方向相反**：DeFi 抵押品清算压力压制反弹，合约杠杆清算（空头强平）增强反弹 |

**机制解释**：交易所空头强平 = 卖方被强制平仓 → 卖压枯竭 → 反弹（131 正门控）；DeFi 清算 = 抵押品被强制卖出 → 持续卖压 → 压制反弹（204 负调制）。两个是不同的市场结构压力面，可以同时用（一个正向门控、一个负向过滤）。

**检验独立性的方法**（若需复核）：
1. **事件重叠度**：定义"激增日"（同 131/204 口径 30d rolling z>1），计算 Jaccard = |A∩B|/|A∪B|，期望 <0.3（204 实测约 0.2 水平）；
2. **phi 系数**（四分相关）：2×2 表（链上激增×交易所激增），phi = (ad−bc)/√((a+b)(c+d)(a+c)(b+d))，|phi|<0.3 → 独立；
3. **增量检验**：wash_cvd 事件按 2×2 分层（链上激增×交易所激增），看四格 24h 超额——若交易所激增格内再分链上激增/不激增无差异 → 链上无增量（同一压力）；204 已显示有差异且方向相反 → 独立且互补。

## 3. 每个候选的正确检验设计要点（避免 128/140 '聚合无调制'教训）

通用纪律（全部适用）：
- **基线必须同期可比**：随机 symbol×时点横截面（同 131/133 口径 draw_random_events n=3000，bootstrap seed=2026），禁止全样本混合；
- **无前视**：事件日-1 或事件时点 asof 取值（同 140 用事件日-1 净流入）；
- **判定口径统一**：24h 超额 CI 下界>0 → GO_LONG / 上界<0 → GO_SHORT / 含0 → NO_GO；n<30 不判；
- **t-stat ≥3.0**（Harvey-Liu-Zhu，M≈20-100）——**这是 128/140 的教训核心**：+0.13pp 或 +2.24% 的 CI 含 0 或贴 0，都不够升级资格；
- **先写机制再测**（QUANT_METHODOLOGY §1：写不出机制的直接淘汰）。

### D. DEX 量
- **数据**：Uniswap v3 各币 WETH 主池小时量（免费 RPC slot0 + Dune 回填历史）；symbol→pool 映射用 parallel_grok_unlockdex 已确认的方法；
- **分层口径**：事件时点 DEX 量 24h 累计 vs 自身 30d 中位数归一（同 121 的 qv24_ratio 公式，但用 DEX 量）；
- **关键检验**：DEX 放量（ratio>1.5）× wash_cvd → 独立增量 vs 121 的 CEX 放量？2×2 联合矩阵（CEX 放量×DEX 放量）看四格——回答"DEX 是 121 的独立增量还是同一放量的两面"；
- **样本预算**：wash_cvd 事件 1348，按 DEX 池覆盖过滤后可能 600-900 有效；**先跑免费 RPC 的当前池，Dune 只拉历史回填**；
- **失败判据**：四格无单调 / DEX 增量 CI 含 0 / 与 CEX 放量事件重叠 >80% → 关闭。

### B. 交易所净流入（小时级分所）
- **数据**：Dune 交易所标签表 + 转账表，Binance 单所 BTC/ETH 小时净流入（对齐币安 wash_cvd 口径）；
- **分层口径**：事件时点 24h 净流入 vs 自身 30d 滚动分位（同 140 但小时级、分所）；
- **关键检验**：140 是日频全所 flash 数据 +2.24% GO_LONG——小时级分所检验这是否是**真实的 Binance 承接信号**而非 CoinMetrics 口径伪影；
- **样本预算**：1348 事件全部可对齐（若 Binance 标签覆盖 2024-06+）；**注意 140 已结论'Dune 免费注册暂不值得'是日频口径**，小时级分所是新增量，但若结果显示与 140 一致（高净流入 GO_LONG），则**不升级**——因为 140 已标记'样本内观察，需独立样本复核'；
- **失败判据**：小时级结果与 140 日频无差异 / 分所与全所口径结果冲突且无法解释 → 关闭（不重复测 140）。

### A. DeFi 链上清算（不重测，只补 204 缺口）
- 204 已测主结果（负调制）；**不花新预算重测**；
- 补测项（在 204 报告基础上，不改判定）：
  1. 激增日定义的稳健性：事件数 vs USD 量 z-score；30d vs 60d 窗口；
  2. 负调制是否在 72h/168h 也成立（204 只报 24h 增量显著负）；
  3. 与 E21 市场级清算风暴的时间重叠（链上激增日是否就是风暴日）；
- **注意方向**：204 负调制 → 若要做门控，是"链上清算激增 = 不做多"的负向过滤，不是 131 式正向门控。

### E. 新币链上筹码（聚焦集中度，不做解锁）
- **数据**：ERC-20 转账表聚合 top-10 holder 集中度（地址聚合，不解析身份——宪法合规）；
- **关键教训**：167 T2 已证横截面精选失败（top50% 反而更差 +8.04% vs +3.60%）；172 解锁日历已证 NO_GO。**E 的唯一新增量是"集中度变化率"**（事件前 7 天 top-10 份额变化），不是集中度水平；
- **样本预算**：s009 新币事件 282（n<30 的子样本直接不判）；
- **失败判据**：集中度变化率分层无单调 / CI 含 0 / 与 167 精选结果同向（都是负）→ 关闭。

### C. 稳定币 per-issuer（跳过，除非先证异质性）
- 前置检验（不花 credits，先看已有数据）：USDT mint 激增日 ∩ USDC mint 激增日 的重叠度；
- 若重叠度高（>50%）→ 无分解价值，直接关闭（128 已证无调制）；
- 若重叠度低 → 才有分解价值（哪类发行人边际买盘），才值得花 credits。

### F. 巨鲸/聪明钱（排除）
- 宪法禁止身份标签；Dune 标签数据也不可用；
- 唯一可做的无身份聚合已归入 E（top-10 集中度不解析身份）。
