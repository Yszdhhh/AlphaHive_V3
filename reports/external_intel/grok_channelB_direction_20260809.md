## 2) 3–5 个机制型方向（贴合：事件驱动 / 山寨永续 / 低频 / 单机）

你们已经证伪或半死的：**funding 水平反转（E17）**、**裸调制（FAM-001 等）**、**横截面 LCS 高换手**。下面优先**永续特有 + 与现有栈可叠加/可独立**。

### 方向 A — 新币生命周期 washout（强化 E19 / E25）
| 项 | 内容 |
|---|---|
| **机制（谁付钱）** | 上市早期：做市/空投猎人/杠杆赌徒 **过度供给空头与追涨多头**；首次真实 washout 后，剩余杠杆被清洗，库存与订单簿从“赌场”切到“幸存者”。付钱的是：**首周杠杆赌徒 + 被迫减仓的做市库存**。持久性来自**每季都有新币流水线**，不是同一个池被套利磨平。 |
| **数据（免费）** | Binance `exchangeInfo` 上线时间；1h klines（含 taker buy）；可选 listing 公告 HTML。不需要付费链上。 |
| **检验要点** | ① 以 **上市日龄分箱**（0–7d / 7–30d / 30–90d / >90d）做 wash_cvd 或 wash+4h；② **强制含下架币**（你们 195 已证明机制跨池，幅度含幸存者）；③ 阈值敏感（日龄边界）预注册后一次；④ 与母边重叠率（E19 已 ~24%）→ 报**独立事件超额**；⑤ 成本：新币点差更大，**必须做冲击/代理点差分层（E25）**。 |
| **为何适合** | 低频事件、单机容量小反而优势（E20 低流动性同向）。 |

### 方向 B — 市场级清算风暴后的篮子反弹（E21 主航道）
| 项 | 内容 |
|---|---|
| **机制** | 跨币同步强平 = 保证金引擎强制卖出，**非信息性抛压**；风暴结束后 OI 下降、funding 从极端回归，边际买家不再是“逃命单”。付钱的是：**被强平的杠杆账户**（交易所保险基金/ADL 是次要）。 |
| **数据** | 币安强平流 / 聚合 liq（你们 Coinalyze 已标定 corr≈0.95）；全市场 OI 变化；BTC+山寨同步回撤幅度。Coinglass 面板可做假设，**回测用自建序列**。 |
| **检验要点** | ① 事件定义必须**市场级**（广度阈值），禁止事后挑币；② 持有 **篮子等权/流动性加权**，不是单币选美；③ 频率~2 次/月 → 前向 n 要耐心（你们已写 ~12 月/30 事件）；④ 分层：风暴后 24h 内是否已 V 反（避免接飞刀 vs 接确认——可与 E18 4h 规则统一）；⑤ **与 wash_cvd 联合**：风暴日×个币 wash 是否超可加（预注册，防多重检验）。 |

### 方向 C — OI 去杠杆象限（不是“高 OI 做多”）
| 项 | 内容 |
|---|---|
| **机制** | 价格↓ + OI↓ = 多头平仓/强平主导（去杠杆）；价格↓ + OI↑ = 新空头堆积（趋势可能延续）。**可交易的是去杠杆尾声的空头拥挤反转或卖压枯竭**，不是 E07 那种“高 OI 分位”。E12 横截面已弱，应改成 **事件条件**：wash 触发时 OI 24–72h 变化符号/幅度。 |
| **数据** | 交易所 OI 历史（Binance futures openInterestHist）；免费但历史长度有限——用滚动 z，不做十年分位玄学。 |
| **检验要点** | ① 四象限在 **wash_cvd 事件内**重做（E12 是全样本横截面，功效与定义都不同）；② 主指标用 **ΔOI / |ret|** 或 OI% 变化，不用绝对高分位；③ 独立窗口 + 成本后净额；④ 若只在高波动 regime 有效 → 记为门控（对齐 E24b/E29），不宣称全域 alpha。 |

### 方向 D — Funding **结构/删失** 而非方向押注（E22 基建 → s014 中性 carry）
| 项 | 内容 |
|---|---|
| **机制** | 费率是多空杠杆不平衡的转移支付。**方向性“极端 funding 反转”已被你们打死（E17）**——因为预测 horizon、封顶/删失、与价格动量纠缠。仍可能活的是：① **市场中性多空配对吃相对 funding**（谁付钱：单边拥挤的赌徒）；② **规则/档位突变**后的短暂错价（参数变更）。持久性：中性 carry 容量被机构啃，但山寨长尾仍有摩擦。 |
| **数据** | premiumIndex / fundingRate 历史；**必须用你们的 `funding_semantics`**（capped→NaN）。 |
| **检验要点** | ① 强制 delta-neutral 或 β-neutral；② 换手与资金费结算对齐（8h）；③ 报告 **扣费后 + 逼空/插针尾部**；④ 禁止把 100× 单位坑再犯一遍；⑤ 与 GRAVEYARD：`funding_level` 方向边不复活。 |

### 方向 E — 换所价差 / 基差事件（低频、有条件）
| 项 | 内容 |
|---|---|
| **机制** | 永续市场是**两层结构**：CEX 主导发现价，DEX/小所跟随；价差≥20bp 常见，但成本+反转使多数套利事后不赚钱。个人单机的 edge 不在 HFT 抹平，而在 **大波动时分所流动性断裂的事件窗口**（提现暂停、保险基金、某所 OI 独增）。付钱的是：**跨所延迟的杠杆与被迫单边平仓者**。 |
| **数据** | 两所以上 mark/index/last（Binance+OKX 免费 REST）；不需要 tick 级。 |
| **检验要点** | ① 定义事件：`|spread|` 超阈值且持续 ≥N 分钟/小时；② 交易的是 **回归或跟随**？预注册一种；③ 成本模型用真实 taker+滑点上界；④ 容量与单笔上限写死；⑤ 学术结论已提示 **强制退出率极高**——默认假设应是 NO_GO，只有事件子集能翻盘才升级。 |

### 优先级建议（结合台账）
1. **A（E19）+ B（E21）** — 最贴“真正跑通”路径  
2. **C** — 给 wash_cvd 换“机制条件”而不是“强度调制”  
3. **D** — 基建与非方向小钱，不指望救主账户  
4. **E** — 研究预算有余再做，先验悲观  

**刻意不推荐现在当主线的：** 再挖 CVD/量能强度调制、谷歌趋势、无确认裸 washout 加仓、传统股指 washout 外推（s002 已打脸）。

## 3) 为什么 2025–26 事件 edge“失效”——以及怎么区分死了 vs regime 差

### 3.1 实战判断（不是故事）

结合公共结构 + 你们自己的证据，**更像“regime 差 + 边际拥挤”，不是“数学恒等式永久消失”**。

| 假说 | 证据倾向 | 对 wash_cvd 的含义 |
|---|---|---|
| **A. 散户结构变化** | 永续占衍生品绝对主导；散户从“现货抄底”更多变成“永续高杠杆赌博”；同时部分流量去 ETF/合规渠道，山寨赌场参与者更职业化 | CVD/盘口“散户踩踏→反转”的 **纯度下降**；同一 wash 形态里混进更多知情/套利流 |
| **B. 套利与同质策略涌入** | 清算热力图、CVD 背离、funding 拥挤成为 2023–24 网红因子；机构/零售 bot 同质 | **调制因子最先死**（大家都加“放量确认”）——这与你们 holdout 上调制全灭 **高度同构**；母边衰减慢于调制，是典型拥挤模式 |
| **C. 市场状态（低波动/降息）** | 你们 **E27：降息×BTC 低波动 = wash_cvd 最差（−4.81% GO_SHORT）**；E24b：山寨合成高波动环境反而强 | **这是目前最硬的“未死、是环境”证据**。低波动 = wash 幅度浅、均值回复弱、假突破多；降息叙事期风险偏好稳定 → 缺“恐慌性错杀” |

另外两条你们已经量过、必须写进叙事：
- **幸存者偏差**：历史 168h 幅度里估计 **20–50%** 来自只看幸存币；前向本来就该下修，不是 2025 突然变傻。  
- **止损与路径**：−10% 止损砍 V 反（180）——“纸面 edge 在、账户跑不通”有时是 **执行/退出**，不是信号期望为 0。

### 3.2 一张判别表：edge 死了 vs regime 差

| 检验 | 若 **regime 差** | 若 **edge 死了** |
|---|---|---|
| **1. 条件期望 E[r\|event, regime]** | 在“历史上该赢的 regime”（高本地波动、清杠杆、非 EASING×低波）仍为正 | 所有预注册 regime 切片期望→0 或负，且同向 |
| **2. 事件定义稳定性** | 事件频率↓或 wash 深度↓，但 **深度足够的事件** 仍有溢价 | 同样深度/同样 CVD 分位，溢价消失 |
| **3. 拥挤代理** | 同质信号相关性↑时衰减，拥挤下降后恢复 | 拥挤代理已回落，溢价仍不回 |
| **4. 成本后净额** | 毛边还在，净边被点差吃掉（流动性 regime） | 毛边先死 |
| **5. 独立机制副本** | E19/E21 等同族机制仍在 | 同族全灭（卖压枯竭类集体失效） |
| **6. 前向事件块（你们 109 纪律）** | 30 事件预警、60–100 正式；**仅差 regime 标签能解释** | 连续 2 个正式块净超额 < 阈值且 CI 上界转负，**限缩 regime 后仍失败** |
| **7. 调制 vs 母边** | 调制死、母边弱但结构同号 | 母边符号翻掉、分布对称噪声 |

**实操判决（建议写进 Owner 规则）：**
- 先做 **双轨**：轨道 1 = 裸 E01/E18 在 holdout；轨道 2 = 同一事件在 **E27 坏环境 / E24b·E29 好环境** 的差分。  
- 若 **好环境仍显著、坏环境为负** → 结论是 **regime 门控**，不是退役母边；下一步是 **缩小适用域 + 降频**，不是再找第 N 个调制。  
- 若 **好环境也死** → 再查成本与执行；仍死 → `decaying`，研究预算转向 E19/E21。  
- **禁止**用“全样本再优化阈值”假装复活——那是把 regime 差拟合成过拟合。

### 3.3 为什么“调制全灭”反而像拥挤、不像机制死亡

强度型调制（量能倍数、深度、CVD z）是 **最低门槛的同质过滤器**，网红策略第一层就会加。  
机制核（价格剧烈洗盘 + 主动卖盘枯竭 + 时间确认）需要 **真的发生踩踏**，在低波动降息年样本变少、信噪比变差——**期望衰减 + 功效不足**会同时出现，看起来像“全坏了”。

一句话：  
**2025–26 更像是“可交易的恐慌事件变少、剩下来的事件被同质 bot 抢跑/摊薄，再叠降息低波 regime”；不是 CVD 数学失效。**  
你们台账里 E27/E24b/E29/E19 已经在指这条路；主战场应从 **“把 wash_cvd 调得更聪明”** 转到 **“只在付钱的人还在的状态交易 + 开发新币/清算风暴独立事件源”**。

## 4) 立刻可执行的 30 天动作（收敛用）

1. **停**：新的强度调制、未预注册因子扫荡。  
2. **判**：wash_cvd holdout 按 E27/E24b/E29 三刀切，输出“死 vs regime”表（上节 7 行）。  
3. **推**：E19 阈值敏感 + 成本；E21 前向风暴只记账不改规则。  
4. **挖**：每周 2h 只从 §1 源收集 **机制句**，进候选池，季度 ≤1 主问题。  
5. **账**：任何“跑通”定义 = paper 账户成本后 + 前向事件块，不看全期漂亮均值。
