## 2. 逐篇深度拆解

### 2.1 Harvey–Liu–Zhu (2016) — 科学测试的「宪法级」门槛

**问题**：学界挖出 300+ 因子；标准 t>2 在「海量检验」下毫无意义。

**方法要点**：
- 统计已发表因子数量与发现速度上升；
- 用 Bonferroni / Holm / FDR 类多重检验框架；
- 给出随时间上升的 **t 门槛序列**；
- 结论：**当代新因子约需 t>3.0**；多数金融研究发现可能为假（呼应医学文献 Ioannidis 式警告）。

**工程映射（你们方向）**：

| 原则 | 落地形态 |
|---|---|
| 记录「测了多少次」 | 检验预算、预注册表、trials 计数 |
| 提高显著性闸 | t≥3 或等价 bootstrap 经济阈值 |
| 发表/宣传偏差 | 失败入库（graveyard），不只展示通过的 |
| 相关检验不独立 | 同一事件池上的多筛选项要减分 / 合并 |

**对「edge 很少」**：HLZ 说这是预期——**正确系统应大量证伪**。吞吐↑若不同时抬门槛 → 假 edge↑。

**局限**：股票截面因子语境；加密样本更短、结构非平稳 → 门槛应 **更严或更依赖前向独立样本**，而非更松。

### 2.2 Bailey & López de Prado — 回测过拟合的「计量武器」

**问题**：试了 N 套参数后挑最好的夏普，历史曲线必然好看。

**核心工具**：
1. **Probabilistic Sharpe Ratio (PSR)**：夏普是否显著高于某基准（考虑非正态）。  
2. **Deflated Sharpe Ratio (DSR)**：在 **选择偏差 + 非正态 + 试了多少次** 后，夏普是否仍可信。  
3. **Probability of Backtest Overfitting (PBO)**：用组合对称交叉验证等估计「选中的配置是过拟合」的概率。  
4. **MinBTL（最小回测长度）**：trials 越多，需要越长样本才敢信。

**工程映射**：

| 原则 | 落地形态 |
|---|---|
| 必须记录 N_trials | 每次网格/灵敏度都算 trials |
| 禁止「只报最佳夏普」 | 报告 DSR 或至少「最佳 vs 中位配置」 |
| 参数敏感即危险 | 你们对加码比例/阈值网格敏感的警惕正确 |
| 短样本 + 多试 = 不可信 | 加密 2–4 年数据 → 少试、严预注册 |

**与豪仔 6-Agent 文对比**：Agent 文提 bootstrap/t，但**几乎不提 trials 记账与 DSR**——这是业余与专业的分水岭之一。

### 2.3 Advances in Financial Machine Learning (López de Prado) — 研究流水线的「工艺书」

**不是策略书**，是 **如何不自欺** 的工艺：

| 概念 | 含义 | 对你们流水线 |
|---|---|---|
| **Triple-barrier** | 止盈/止损/时间三维标签，贴近真实交易结果 | 虚拟盘规则应与标签一致（你们 A/B 账户思想） |
| **Purged / Embargo CV** | 时间重叠标签泄漏 | 事件研究 asof、冷却期、禁止随机 k-fold 乱切 |
| **Meta-labeling** | 一级定方向，二级定「做不做/做多大」 | 等于「过滤器 + 仓位」：wash_cvd 方向 + regime/确认做 filter |
| **CPCV / PBO** | 多路径回测评估过拟合 | 独立窗口、episode 切分 |
| **Fractional differentiation** | 平稳化同时保记忆 | 高级项，非必须 |

**深度操作意义（meta-labeling 特别贴合你们）**：
- 一级模型/规则：事件信号（washout+CVD）  
- 二级：是否执行（4h 确认、VIX、GMM 后验、流动性）  
- **二级失败 ≠ 一级机制死亡**；可只关过滤器  
- 这比「再挖一个全新方向」更符合「edge 少、要保护主 edge」

**权威边界**：书偏 ML 与高频/中频股票执行语境；加密事件研究可吸收精神，不必全盘 ML 化。

### 2.4 McLean–Pontiff (2016) — 「衰减」的顶级实证

**发现**（股权特征预测文献）：
- 样本外已有衰减；
- **论文发表后**，可预测性再降，合计大约 **35% 量级**的 post-publication decay；
- 样本内越强、越容易被套利的，发表后掉得更狠。

**机制叙事**：
- 一部分是统计偏差（数据挖掘）出样本就没；  
- 一部分是 **被知情资金交易掉**（真正的 alpha 衰减）。

**工程映射**：

| 阶段 | 含义 |
|---|---|
| 历史显著 | 仅是「候选资格」 |
| 发表/公开/拥挤 | 预期收益下修 1/3 量级（数量级参考，非加密常数） |
| 前向影子 | **必须**，且应用 **经济阈值** 而非「还显著吗」 |
| 退出 | 衰减到成本下沿 → 缩仓/退役，不是「再调参救活」 |

**对你们**：s001 历史好看、前向要数月——**文献支持「慢」是对的**；公开越多的简单规则，前向应假设更弱。

### 2.5 AQR — 因子「事实与虚构」与拥挤叙事

**有用认知**（Fact/Fiction 系列精神）：
- 因子长期 hump 不等于失效；短期回撤可被错误解读为「拥挤致死」。  
- **若拥挤导致失效，形态更像缓慢趋零**，而不是突然深负；突然深负可能是 **被逆向拥挤/做空因子** 等。  
- 经济机制 + 多市场/多时段稳健 > 单一回测曲线。

**工程映射**：
- 衰减监测要区分：**缓慢磨灭** vs **结构性反转** vs **regime 子集失效**；  
- 退出规则应预注册（「点估计低于 X 连续 K 块」），避免回撤时情绪砍策略、趋势时加码。

---

### 2.6 Maven Securities — Alpha Decay 与「慢」的成本

**内容性质**：产业短文，非顶刊，但问题定义清晰。

**要点**：
- 均值回复类 alpha 若 **延迟执行**，美欧股票样本上可损失数个百分点年化量级（其图示结果）；  
- 波动高时，信息嵌入更快，**延迟更贵**；  
- 原因：拥挤、技术加速、成本下降带来更多竞争。

**对个人加密的翻译**：
- 高频/微观 alpha：延迟与共置决定生死 → 个人慎入；  
- **事件型中低频**（你们 wash_cvd 24h–168h）：对毫秒不敏感，对 **数据口径与确认滞后** 敏感（4h 确认是「故意买延迟换质量」——文献支持这种 trade-off 可显式算）。  
- 衰减监测应含：**信号到成交的滞后敏感性**。

---

### 2.7 因子信息衰减与再平衡（应用研究层）

Flint et al. 类结论（经 Alpha Architect 等转述）：
- **价值**信息衰减慢 → 再平衡可数月；  
- **动量**衰减快 → 再平衡更勤；  
- 再平衡频率应匹配 **信息半衰期**，不是统一日频。

**工程映射**：
- 每个 edge 在 alpha card 写清：**持有 horizon + 预期半衰期 + 重估频率**；  
- 衰减检测窗口用 **事件计数** 比日历月更适合稀疏事件策略（你们已走事件窗口是对的）。

---

### 2.8 经典组合层：IR / Breadth / 容量（Grinold-Kahn 精神）

**公式直觉**：信息比率 ≈ IC × √Breadth（在理想化假设下）。

**含义**：
- 弱信号 + 多次独立下注 可构成组合；  
- 但 **相关事件不独立** 时 breadth 被高估；  
- 容量大则冲击吃 alpha。

**对「几刀也行」个人系统**：
- 优势是 **低容量**；  
- 劣势是 **breadth 小**（事件少）→ 必须接受 **慢验证** 与 **组合多不相关小 edge**，而不是单策略高夏普幻想。

## 3. 权威流水线：合成「标准研究 OS」

下列是文献共识拼成的流水线，可与豪仔 6-Agent **对照**——左边是权威，右边是常见 X 营销夸大。

```
[1] 经济机制 / 假设预注册     ← 禁止无机制挖矿
[2] 数据契约与无泄漏标签       ← purged / asof / 成本
[3] 单次定义锁定后回测         ← 记录 N_trials
[4] 统计闸 (t/DSR/bootstrap)   ← HLZ + Bailey
[5] 稳健性 (子样本/敏感/regime)← AFML + AQR
[6] 增量/已知因子残差          ← 股票用 FF；加密用「相对已有 edge 边际」
[7] 前向影子 / 纸交易          ← 标签与执行一致
[8] 小资金实盘                 ← 容量与摩擦
[9] 衰减监测 + 预注册退出      ← McLean + 事件窗口
[10] 墓地与预算回收            ← 防止重复挖坑
```

**X 6-Agent 文做对的**：1–6 骨架、Maker-Checker、状态记忆、衰减模式。  
**做错/夸大的**：每晚新 alpha、股票 20 年模板硬套、不强调 trials/DSR、用吞吐替代通过率。

## 4. 衰减与退出：文献级「设计清单」

### 4.1 衰减的三种形态（应用时要分开记）

| 类型 | 表现 | 典型原因 | 动作 |
|---|---|---|---|
| **统计假阳** | 前向立刻没 | 数据挖掘 | 退役，记 graveyard |
| **缓慢拥挤衰减** | 超额磨向 0 | 公开/资金涌入 | 缩仓、降杠杆、观察 |
| **结构断裂** | 符号翻转/单 regime 死 | 机制变了 | 限缩适用域或退役 |

### 4.2 退出机制的文献兼容设计（原则级）

1. **预注册**：进入 shadow 前写清「什么叫 decay / 什么叫 retire」。  
2. **经济阈值优先于 p 值**：成本后净期望 < X 连续 K 个独立块 → watch。  
3. **事件计数窗口**优于日历（稀疏信号）。  
4. **先限缩后杀死**：仅某 regime 失效 → 缩域；全域失效 → 退役。  
5. **禁止用调参「救活」**：改参 = 新策略 + 新样本起点 + 新 trials。  
6. **公开/复制风险**：简单规则假设前向弱于历史（McLean 量级作悲观情景）。

## 9. 可引用的「金句级」结论（写 alpha card / 宪法用）

1. **多数声称的发现可能是假的**（HLZ）。  
2. **试得越多，同一夏普越不值钱**（Bailey/LdP）。  
3. **方向与是否下注应拆成两层**（meta-labeling）。  
4. **公开与拥挤会吃掉一大块样本内 alpha**（McLean-Pontiff）。  
5. **衰减监测与研究流水线同等重要**（产业共识）。  
6. **验证慢、通过少，是纪律系统的正常稳态**，不是必须用 Agent 喷泉解决的缺陷。
